Iset

PBDSによる順序統計付き集合。Imapは値を持つ順序統計付き連想配列。

以下のPBDS用ヘッダーとusing宣言は #define int long long より前に置く
1#include <ext/pb_ds/assoc_container.hpp>
2#include <ext/pb_ds/tree_policy.hpp>
3using namespace __gnu_pbds;
4template <typename T, typename S = null_type>
less<T>をless_equal<T>にするとmultiset,multimapになる
5struct Iset : tree<T, S, less<T>, rb_tree_tag, tree_order_statistics_node_update> {
6 using base = tree<T, S, less<T>, rb_tree_tag, tree_order_statistics_node_update>;
7 using base::base;
小さい方からk番目（0-indexed）の要素のイテレータを返す。範囲外ではend()
計算量 O(log N)
8 auto kth(size_t k) { return this->find_by_order(k); }
x未満のキーの個数を返す
計算量 O(log N)
9 size_t rank(const T& x) { return this->order_of_key(x); }
10};
