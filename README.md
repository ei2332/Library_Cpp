# Library_Cpp

> [!NOTE]
> このプロジェクトでは、生成AIをコードの作成・改善・テスト・ドキュメント整備などに利用しています。

## プロジェクトの目的/概要
atcoderやICPC等で利用する競プロ用テンプレートを整備・保存・管理する

## 利用方法
プログラムにはプログラムで処理するためのコメントが含まれます。  
以下の環境下を想定します。
- C++20
- GCC13
